# 1.0.0 五项回归修复

本次纳入 1.0.0 发布。已有 0.2.4 发布文件保持不变。

1. **旧任务中的人工校对**：保留人工修改的原文、译文、方向、竖排、保留原文设置和确认状态。人工区域按原始字形坐标固定，其余文字重新组合；即使新算法改变了段落边界，也不把人工区域与自动区域重复加入。重复正文按位置和内容匹配，避免把另一段相同文字的缓存挪到当前段落。
2. **页码范围与续翻**：扩大、缩小或使用等价的页码格式均保留已分析页面、译文和累计用量。未选中页面保存在内部缓存，当前翻译、视觉核对、估算、校对列表和导出只处理所选页面。识别参数改变需要重新分析时，匹配的译文和人工区域仍复用；翻译语言、模型或术语改变时，原来的自动译文失效规则继续生效。
3. **竖排中的公式**：以完整矢量对象放入竖排列，字符与公式分别占用可计算的空间。公式不会变成可见的 `[[MATH_0]]`。标记缺失、放不下或存在位置冲突时保留原文并提示核对。
4. **普通字体公式**：识别常见赋值、等式、四则运算、幂和括号表达式，例如 `x = (a+b)/c`。原生 PDF 中按字形拆成受保护的矢量对象；没有矢量元数据的旧稿和手工原文使用文本保护。模型缺失公式占位符时拒绝结果并按原规则有限重试。导出也检查没有矢量标记的公式，阻止把已变更的表达式直接写回。自然语言连字符词、网址和数值的既有保护继续保留。
5. **过时的排版提示**：每次导出重新计算公式、边界、图片冲突和溢出提示。修改后已能安全放下的区域不再带旧的“无法完整放下”提示。OCR 置信度、模型翻译异常等提示不因此清除；仅当它们本身得到核对处理后才解除。

分析结构由版本 3/4 升级到 5；项目 JSON 的 schema 仍为 1。常见代数识别不代表可以识别任意复杂数学排版；无法确认或无法安全放下的内容继续保留原文供人工核对。已经由旧版本覆盖而不存在于当前任务中的人工数据，不能凭空恢复。

本地验证使用合成 PDF、模拟接口和用户指定 PDF 的独立诊断输出，未使用真实付费密钥。测试记录位于本地 `test-output/five-fixes-20261030/`，不进入公开发行包。
