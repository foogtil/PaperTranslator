# 1.1.0 任务与接口修订（2026-11-02）

本修订修复续传、多个窗口、图片开关、导出页码、原文更新与接口超时的六类问题。版本号保持 1.1.0。

- **续传**：自动任务以原 PDF 路径识别，不再随输出目录变化。打开已保存项目后，“开始 / 继续翻译”沿用该项目的译文和人工校对，再存入内部任务目录。已有旧任务会迁移，旧项目保留。
- **多个窗口**：同一文献处理期间，其他窗口不能同时运行或保存该文献。任务结束或进程退出后自动释放占用；较旧的校对快照不能覆盖新进度，需先点“载入校对”。JSON 保存使用各自的临时路径。
- **图中文字开关**：关闭后，本地 OCR 与视觉补充会屏蔽检测到的图片区域，已有图内标签不参与翻译和替换。正文与图题仍可翻译；缓存标签译文保留，重新开启时可复用。全页扫描背景仍按扫描正文处理。图形边界检测本身仍存在复杂版面识别限制。
- **导出页码**：直接导出使用界面当前的页码范围，未选页保留原文。如果新范围包含尚未分析的页面，会提示先分析，不会静默忽略。
- **原 PDF 更新**：重新分析时将旧项目保存为带 `before-source-change` 标识的独立项目，再建立新分析。不会把旧坐标或自动译文套用到新内容；旧项目的原 PDF 校验仍保持严格。
- **接口等待**：读取等待使用服务商配置的 `timeout`（默认 180 秒），取消能中断正在等待的网络请求。已经发出请求后的读取超时、写入失败和断流不自动重发，避免重复生成；用户可以“继续翻译”重试未完成区域。连接失败及服务商明确返回的可重试状态仍有有限重试。

新增提示已覆盖现有界面语言。测试不使用真实 API Key，不产生服务商调用费用。实际网络取消验证仅连接本机临时 HTTP 服务。

原有翻译模型、完整段落、整图语义、公式保护和排版质量规则保持一致。本修订不承诺任意论文全自动排版无误。
